## 代码审查清单

### 正确性

- 边界条件：空输入、超大输入、并发
- 错误处理：异常吞掉了吗？错误信息够定位吗？
- 数据一致性：事务、回滚、幂等

### 安全

- 用户输入校验
- SQL 注入 / 路径穿越 / XSS
- 鉴权与权限边界

### 性能

- N+1 查询
- 不必要的全表扫描或大对象拷贝
- 缓存失效策略

### 可维护性

- 命名是否自解释
- 函数职责是否单一
- 是否引入了不必要的抽象

### 测试

- 覆盖核心路径
- 边界用例
- 不依赖外部状态
